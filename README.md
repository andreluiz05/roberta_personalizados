## 📌 Sobre o Projeto
Landing page institucional e catálogo digital desenvolvido para a **Roberta Personalizados**, uma marca focada em eternizar momentos através de produtos afetivos de alta qualidade (ímãs, topos de bolo, bottons, chaveiros, etc.). 

O projeto foi construído sob uma **Arquitetura Front-End Sênior**, priorizando extrema velocidade, ranqueamento no Google (SEO Técnico Avançado) e alta conversão para o WhatsApp da marca.

---

## 🚀 Principais Features (O que torna este site incrível?)

- **PWA (Progressive Web App):** O site possui um `manifest.json` que permite aos clientes "instalarem" o catálogo na tela inicial do celular como um aplicativo nativo.
- **Engenharia de Performance:** Todas as imagens foram convertidas para o moderno formato `.webp` e carregam via *Lazy Loading*. 
- **SEO Sênior:** 
  - `sitemap.xml` e `robots.txt` perfeitamente configurados.
  - Implementação de dados estruturados (**JSON-LD Schema.org**) como *LocalBusiness*.
  - Tags **Open Graph (OG)** e **Twitter Cards** para que os compartilhamentos no WhatsApp e Instagram fiquem perfeitos com a foto da marca.
- **Mobile-First Design:** O layout foi pensado primeiramente na tela do celular e adapta-se fluidamente para monitores Ultrawide usando *Tailwind CSS*.
- **Código Limpo (SOLID):** O JavaScript (`main.js`) foi construído de forma 100% modular, respeitando o princípio da Responsabilidade Única.

## 🛠️ Tecnologias e Ferramentas

| Ferramenta | Propósito |
| :--- | :--- |
| **HTML5 Semântico** | Estruturação altamente acessível (`<nav>`, `<article>`, `<section>`). |
| **Tailwind CSS** | Estilização via CDN utilizando variáveis dinâmicas de cores da marca. |
| **Vanilla JavaScript** | Lógica de interação nativa (menus, busca, carrosséis) sem bibliotecas pesadas. |

## 📂 Arquitetura de Pastas (Padrão Sênior)

```text
📁 roberta-personalizados/
├── 📁 site/                  # Raiz da aplicação que vai para o ar
│   ├── 📁 css/               
│   │   ├── style.css         # Animações globais e estilos vitais
│   │   └── responsivo.css    # Media Queries e tipografia fluida
│   ├── 📁 js/                
│   │   ├── main.js           # Módulos: MobileMenu, ProductCarousel, SearchOverlay
│   │   └── tailwind-config.js# Definições do Design System (Cores e Fontes)
│   ├── 📁 images/            # Assets convertidos para .webp
│   ├── index.html            # Estrutura principal do site
│   ├── manifest.json         # Configurações do App Mobile (PWA)
│   ├── robots.txt            # Regras para os motores de busca
│   └── sitemap.xml           # Mapa do site para indexação acelerada
```
